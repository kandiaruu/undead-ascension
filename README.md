# Undead Ascension

A tactics game about a necromancer: raise the dead, build an army and descend ever deeper — alone or with up to 3 friends in co-op.

## ⬇️ Download

**[Latest version](https://github.com/kandiaruu/undead-ascension/releases/latest)** — Windows: `UndeadAscension-*-windows.zip`, Linux: `UndeadAscension-*-linux.tar.gz`.

The game tells you in the main menu when a new version is out. Online play (online character, co-op, PvP) works only in the latest version.

## How to run

### Windows

1. Extract the **whole** archive to any folder (don't run it from inside the zip).
2. Run `UndeadAscension1.exe`.
3. If Windows shows "Windows protected your PC", click **More info → Run anyway** (the game isn't code-signed yet).

### Linux

```bash
tar -xzf UndeadAscension-*-linux.tar.gz
./UndeadAscension/UndeadAscension.x86_64
```

## Online, co-op and PvP

In the game menu: **Link Discord** → type `/link` with the code on the game's Discord server → **Online character**.

- **Online character** — your save lives on the server, so you can play it from any computer.
- **Co-op** — pause menu → **Co-op** → create a party or join with a code. Up to 4 players share one world, fight together and split the loot.
- **PvP** — challenge other players right from Discord.

Discord: https://discord.gg/FBFxGqFJWp
