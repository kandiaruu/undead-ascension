# Undead Ascension

Тактическая игра про некроманта: поднимай мёртвых, собирай армию и спускайся всё глубже.
*A tactics game about a necromancer: raise the dead, build an army and descend ever deeper.*

## ⬇️ Скачать / Download

**[Последняя версия (Windows) / Latest version (Windows)](https://github.com/kandiaruu/undead-ascension/releases/latest)** — файл `UndeadAscension-*.zip`.

## Как запустить / How to run

1. Распакуй архив **целиком** в любую папку (не запускай из архива).
   *Extract the whole archive to any folder (don't run it from inside the zip).*
2. Запусти `UndeadAscension1.exe`.
   *Run `UndeadAscension1.exe`.*
3. Если Windows пишет «Windows защитила ваш компьютер» — нажми **Подробнее → Выполнить в любом случае** (у игры пока нет цифровой подписи).
   *If Windows shows "Windows protected your PC", click **More info → Run anyway** (the game isn't code-signed yet).*

## Онлайн и PvP / Online and PvP

В меню игры: **Привязать Discord** → в Discord-сервере игры введи `/link` с кодом → **Онлайн-персонаж**.
*In the game menu: **Link Discord** → type `/link` with the code on the game's Discord server → **Online character**.*

Discord: https://discord.gg/FBFxGqFJWp
