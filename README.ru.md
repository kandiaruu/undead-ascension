# Undead Ascension

Тактическая игра про некроманта: поднимай мёртвых, собирай армию и спускайся всё глубже — один или вместе с друзьями (до 4 игроков в кооперативе).

## ⬇️ Скачать

**[Последняя версия](https://github.com/kandiaruu/undead-ascension/releases/latest)** — Windows: `UndeadAscension-*-windows.zip`, Linux: `UndeadAscension-*-linux.tar.gz`.

Игра сама подскажет в главном меню, когда выйдет новая версия. Онлайн (онлайн-персонаж, кооператив, PvP) работает только в последней версии.

## Как запустить

### Windows

1. Распакуй архив **целиком** в любую папку (не запускай из архива).
2. Запусти `UndeadAscension1.exe`.
3. Если Windows пишет «Windows защитила ваш компьютер» — нажми **Подробнее → Выполнить в любом случае** (у игры пока нет цифровой подписи).

### Linux

```bash
tar -xzf UndeadAscension-*-linux.tar.gz
./UndeadAscension/UndeadAscension.x86_64
```

## Онлайн, кооператив и PvP

В меню игры: **Привязать Discord** → в Discord-сервере игры введи `/link` с кодом → **Онлайн-персонаж**.

- **Онлайн-персонаж** — сейв хранится на сервере, играть им можно с любого компьютера.
- **Кооператив** — меню паузы → **Кооператив** → создай группу или войди по коду. До 4 игроков в одном мире: бьётесь вместе и делите добычу.
- **PvP** — вызывай других игроков прямо из Discord.

Discord: https://discord.gg/FBFxGqFJWp
